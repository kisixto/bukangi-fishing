# bukangi-fishing — 부캉이 낚시터

물고기를 낚아 팔고, 번 돈으로 장비를 강화하고 새 낚시터를 여는 캐주얼 낚시 게임입니다. 설치 없이 `index.html` 하나로 동작합니다.

## 플레이

`index.html`을 브라우저로 열면 바로 시작됩니다. GitHub Pages를 켜면(Settings → Pages → Branch: `main`) 링크로도 플레이할 수 있습니다.

| 조작 | 키보드 | 화면 |
|---|---|---|
| 던지기(두 번: 게이지 시작 → 던지기) · 챔질 · 감기(누르고 있기) | 스페이스 | 빨간 버튼, 또는 장면 터치 |
| 들기(릴낚시) | ↑ 또는 W | 노란 버튼 |
| 방식 전환 | 1 찌낚시 / 2 릴낚시 | 하단 전환 버튼 |

## 규칙

**낚시 흐름**
- 던지기 → 입질 → 챔질 → 릴 감기 → 포획. 거리가 0이 되면 이름, 크기, 무게, 등급, 가격이 나옵니다.
- 포획 결과 창에서 **바로 팔기**를 누르면 살림망에 넣지 않고 그 자리에서 팝니다.

**캐스팅**
- 던지기를 누르면 거리 게이지가 왕복하고, 한 번 더 누른 순간의 위치로 12m~40m 사이를 던집니다. 수면에 떨어질 지점이 미리 표시됩니다.
- 멀리 던질수록 비싼 등급의 물고기가 잘 오고, 가까이 던지면 덜 옵니다. 게이지 한가운데가 기준 밸런스이고, 등급 번호마다 가중치가 최대 1.35배씩 오르거나 내려갑니다. 배낚시 기준 1마리 기대 판매가는 가장 가까이 약 590원, 가운데 약 760원, 가장 멀리 약 960원입니다.
- 대신 멀리 던질수록 물고기가 멀리서 걸려 끌어올 거리가 1.15배로 늘고, 가까이 던지면 0.85배로 줄어듭니다. 좋은 물고기를 노리면 그만큼 놓칠 위험도 커집니다.
- 릴 감기 단계에서는 장력 바늘을 초록 구간에 유지해야 합니다. 구간을 넘으면 줄 내구가 닳아 끊어지고, 구간 아래로 2.2초 넘게 있으면 물고기가 바늘을 털고, 던진 거리의 1.3배보다 멀어지면 도망갑니다.
- 크고 비싼 물고기일수록 초록 구간이 좁아지고, 당기는 힘이 세고, 갑자기 돌진하거나 다가와서 줄이 느슨해지는 일이 잦습니다.

**낚시 방식**
- 찌낚시: 찌가 톡톡 흔들리는 건 간보기입니다. 찌가 쑥 잠기는 순간 챔질해야 하고, 감기는 버튼 하나로 합니다.
- 릴낚시: 입질이 오면 움직이는 커서를 초록 구간에 맞춰 챔질합니다. 감을 때는 들기로 대를 세워 끌어오고, 대를 내리는 동안 감는 펌핑이 가장 빠릅니다. 대를 세우면 물고기 돌진을 일부 흡수합니다.
- 물고기마다 선호 방식이 있습니다. 맞는 방식이면 초록 구간이 넓고 저항이 약하며, 그 종이 1.5배 더 자주 나옵니다. 낚시터 추천 방식과 같으면 입질도 빨리 옵니다.

**등급과 가격**
- 가격 = 기준가 × (길이 ÷ 평균 길이)². 같은 종도 크기에 따라 가격과 등급이 달라집니다.
- 등급은 판매가 기준으로 일반(0원~), 고급(60원~), 희귀(200원~), 영웅(700원~), 전설(2,500원~)입니다.

**부캉이와 부산**
- 실내 낚시터와 부산을 뺀 곳에서 입질 1회당 0.4% 확률로 부캉이가 낚입니다. 미끼를 강화하면 확률이 오릅니다(황금 미끼 1.04%).
- 부캉이를 잡으면 부산 이용권 1장을 받고, 1장으로 부산에서 150초 동안 낚시할 수 있습니다. 부산에는 황금 고등어, 해운대 은갈치, 태종대 다금바리, 오륙도 돗돔 같은 전용 어종이 나옵니다.

**성장**
- 장비 4종을 각각 5단계까지 강화합니다. 낚싯대는 초록 구간, 릴은 감기 속도, 낚싯줄은 장력 초과를 버티는 시간, 미끼는 희귀 출현·큰 개체·부캉이 확률을 올립니다.
- 낚시터는 실내 낚시터(튜토리얼) → 강(150원, 튜토리얼 보상으로 바로 해금) → 방파제(1,500원) → 배낚시(4,000원) 순서로 엽니다. 기대 판매가로 계산하면 강 → 방파제와 방파제 → 배낚시가 각각 30마리 남짓입니다.
- 살림망은 15칸이고, 가득 차면 상점에서 팔아야 다시 던질 수 있습니다.

**도감 완성 보상**
- 낚시터의 물고기를 모두 한 번 이상 잡으면 작은 편의 효과를 하나씩 받습니다. 받은 효과는 영구 적용됩니다.

| 낚시터 | 보상 |
|---|---|
| 실내 낚시터 (3종) | 살림망 +2칸 |
| 강 (7종) | 챔질 판정 10% 넓어짐 (게이지 구간과 찌 반응 시간) |
| 방파제 (8종) | 느슨함 허용 +0.3초 |
| 배낚시 (6종) | 입질 대기 10% 단축 |
| 부산 전용 (4종) | 부산 이용 시간 +30초 |

**연출과 소리**
- 물고기를 낚으면 수면 위로 튀어 오르는 연출이 나옵니다. 희귀 이상은 빛줄기, 영웅 이상은 반짝이, 전설과 부캉이는 화면이 번쩍입니다. 넘기기 버튼이나 스페이스로 건너뛸 수 있습니다.
- 던지기, 찌 입질, 챔질, 릴 감기, 장력 경고, 줄 끊김, 포획, 판매, 강화에 효과음이 있고, 휴대폰에서는 진동도 납니다. 효과음은 파일 없이 브라우저(WebAudio)에서 합성합니다.
- 상단 소리 버튼으로 효과음과 진동을 함께 끌 수 있습니다.
- 진동은 기기마다 지원 범위가 다릅니다.
  - 안드로이드 크롬: GitHub Pages나 파일로 직접 열면 진동합니다. 다른 페이지 안에 끼워 넣은 화면(iframe)에서는 브라우저가 진동을 막습니다.
  - 아이폰: 웹 진동 기능을 지원하지 않아서, iOS 18 이상에서 스위치 토글 햅틱으로 대신 울립니다. 그보다 낮은 버전에서는 진동이 없습니다. 설정 → 사운드 및 햅틱 → 시스템 햅틱이 켜져 있어야 합니다.
  - 소리 버튼을 켤 때 짧게 한 번 진동하므로, 그걸로 진동이 되는지 확인할 수 있습니다.

**기타**
- 첫 실행 때 8단계 튜토리얼이 나오고, 끝내면 150원을 받아 강을 바로 열 수 있습니다. 건너뛸 수도 있습니다.
- 도감에 종별 마릿수, 최대 크기, 최고 등급이 기록됩니다.
- 진행 상황은 브라우저의 localStorage에 저장됩니다. 도감 아래 버튼으로 초기화할 수 있습니다.

**기록 옮기기 (휴대폰 ↔ 컴퓨터)**
- 기록은 기기와 브라우저마다 따로 저장되므로, 다른 기기로 옮기려면 저장 코드를 씁니다. 서버 없이 동작합니다.
- 보내는 기기: 도감 → 기록 옮기기 → 코드 복사. 카카오톡 나에게 보내기나 메모 앱으로 다른 기기에 보냅니다.
- 받는 기기: 도감 → 기록 옮기기 → 코드 붙여 넣기 → 불러오기. 받을 기록(금액, 도감 수, 낚시터)을 먼저 보여 주고, 한 번 더 누르면 이 기기의 기록을 덮어씁니다.
- 코드는 `BKG1.`로 시작합니다. 메신저에서 줄바꿈이 섞여도 그대로 붙여 넣으면 됩니다.
- 같은 기기라도 GitHub Pages 주소와 다른 주소(예: 아티팩트 링크)는 기록이 따로 저장됩니다.

## 밸런스 표

`bukangi-fishing-balance.xlsx`에 물고기별 가격·등급·난이도·장력 구간, 낚시터별 출현 확률과 1마리 기대 판매가, 다음 낚시터까지 기대 마릿수, 캐스팅 거리별 기대 판매가, 장비 비용과 부캉이 확률, 도감 완성 보상이 수식으로 정리되어 있습니다. 값은 현재 게임과 같습니다. 표를 바꿔도 게임은 바뀌지 않으니, 정한 값은 `index.html` 맨 위 `CONFIG`에 옮겨 주세요.

## 구조

모든 밸런스 수치는 `index.html` 맨 위 `CONFIG` 한 곳에 있습니다. 코드는 Unity로 옮기기 쉽게 다음처럼 나뉘어 있습니다.

| 구역 | 하는 일 | Unity 대응 |
|---|---|---|
| `CONFIG` | 물고기, 낚시터, 장비, 등급, 미니게임 수치 | ScriptableObject |
| `SAVE` | 저장과 불러오기 | SaveSystem |
| `ECONOMY` | 등급 판정, 물고기 생성 | FishFactory |
| `SOUND` | 효과음 합성, 진동 | AudioSource + 클립 |
| `FISHING` | 상태머신, 챔질 게이지, 찌 타이밍, 장력, 포획 연출 | FishingController |
| `TUTORIAL` | 단계별 안내 | TutorialManager |
| `RENDER` | 도형 그리기, `SPRITES` 교체 지점 | SpriteRenderer |
| `UI` | HUD, 상점, 낚시터, 도감 | UGUI 패널 |

그래픽은 지금 도형으로 그립니다. `loadSprite('fish', 'bungeo', 'bungeo.png')`처럼 이미지를 등록하면 그 대상만 이미지로 바뀝니다.
